# StatSkill AI — Competency Intelligence Platform

StatSkill AI is an AI-powered competency intelligence and personalized learning platform for India's Official Statistical System (Ministry of Statistics & Programme Implementation - MoSPI).

## Design System

- Primary color: #1A3A5C (dark navy)
- Secondary color: #2E86AB (soft blue) 
- Accent: #F39C12 (gold for warnings)
- Success: #27AE60 (green)
- Danger: #E74C3C (red)
- Background: #F8F9FA (light grey)
- Font: Inter font family
- Clean, professional, enterprise-grade UI

## Features & Pages

- **Sign In & Sign Up**: Officer onboarding & profile registration
- **Employee Dashboard**: Competency snapshot gauge, priority skill gaps, and course recommendations
- **My Competency**: Level tracking, evidence logging, and PDF report exporting
- **Skill Gap Analysis**: Benchmark tables with filters and AI insight panel
- **Personalized Learning Path**: Vertical progress timeline and module status
- **Material Analyzer**: File extraction & automated MCQ assessment generator
- **Quiz Interface**: Timed assessment interface with radio question navigation

## Development

Requires Node.js and npm:

```sh
npm install
npm run dev
```
